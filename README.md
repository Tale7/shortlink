# 高并发短链接服务

## 项目简介
本项目实现了一个高并发短链接生成与跳转服务，支持将长链接转换为短码，并通过短码快速跳转。系统采用 **Redis 缓存 + MySQL 持久化** 双层存储，引入 **布隆过滤器** 防止缓存穿透，有效保护后端数据库。基于 Flask 提供 RESTful API，单机可支撑高 QPS 访问。

## 技术栈
- **后端框架**：Flask
- **缓存**：Redis（热点数据，7天过期）
- **数据库**：MySQL（持久化存储）
- **防穿透**：布隆过滤器（Python `pybloom-live`，文件持久化）
- **编码**：Base62 将自增 ID 转为短码

## 核心功能
- **短链接生成**：`POST /shorten`，接收长链接，返回短码。
- **短链接跳转**：`GET /<short_code>`，自动重定向到原链接。
- **高性能**：Redis 缓存热点短码，布隆过滤器快速拦截不存在短码，避免数据库压力。
- **数据持久**：所有映射关系同时写入 MySQL，Redis 缓存失效后可回填。

## 布隆过滤器防穿透
当恶意请求大量不存在的短码时，传统流程会逐次查询 Redis 和 MySQL，导致缓存穿透。本项目在查询入口增加布隆过滤器：
- 布隆过滤器存储所有已生成的短码。
- 判断短码不存在时，直接返回 404，不查询任何后端存储。
- 布隆过滤器通过文件 `bloom.dat` 持久化，服务重启后自动加载，保证数据不丢失。

## 环境要求
